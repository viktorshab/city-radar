[TITLE]Радар міста — встановлення для Windows
[SHORTCUTNAME]Радар міста.lnk
[NOPY1]Python на цьому комп'ютері не знайдено.
[NOPY2]1. Завантажте й встановіть Python з офіційного сайту:
[NOPY3]       https://www.python.org/downloads/
[NOPY4]2. На першому екрані інсталятора ОБОВ'ЯЗКОВО поставте галочку
[NOPY5]   "Add python.exe to PATH" внизу вікна — без неї команда python
[NOPY6]   не запрацює.
[NOPY7]3. Після встановлення запустіть install_windows.bat ще раз.

[DONE02]   TG_API_ID, TG_API_HASH, TG_PHONE, BOT_TOKEN, TARGET_CHAT_ID.
[DONE03]   Див. README.md / SETUP_WITH_CLAUDE_CODE.md — там пояснено,
[DONE04]   де їх узяти.

[DONE07]3. Запустіть радар ярликом «Радар міста» на робочому столі
[DONE08]   (або файлом start_windows.bat). Іконка з'явиться біля годинника.
[DONE09]Якщо не хочете підключати другий акаунт Telegram — є режим без

[DONE11]публічні сторінки каналів, але працює лише у відкритому вікні
[DONE12]консолі, без іконки в треї. Див. docs/RUN_MODES.md, розділ Б.
