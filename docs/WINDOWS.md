# Радар міста на Windows — покроково

Після налаштування радар живе іконкою в треї біля годинника: колір показує стан,
правий клік відкриває меню, подвійний — вікно налаштувань. Усе, що вміє
застосунок macOS, є й тут.

> ⚠️ Радар — допоміжний інструмент. Він може пропустити справжню загрозу або
> підняти хибну. Офіційні сигнали тривоги, застосунки й сирени — головні.

## 1. Поставити Python (один раз)

Якщо Python ще немає: [python.org/downloads](https://www.python.org/downloads/)
→ завантажити 3.11 або новіший → у першому вікні інсталятора **обов'язково**
поставити галочку **«Add python.exe to PATH»**.

## 2. Завантажити радар

На сторінці репозиторію: **Code → Download ZIP**, розпакувати в зручне місце
(наприклад `Документи\city-radar`). Або `git clone`, якщо звикли до git.

## 3. Встановити

У папці радара двічі клацніть **`install_windows.bat`**. Він:

* створить окреме середовище `.venv` і поставить туди все потрібне (системний
  Python не засмічується);
* створить ярлик **«Радар міста»** на робочому столі;
* запитає, чи запускати радар разом із Windows (автозапуск).

Якщо Windows покаже «Windows захистила ваш комп'ютер» — **Докладніше →
Виконати в будь-якому разі**: це звичайний скрипт із цієї папки, його можна
відкрити Блокнотом і прочитати.

## 4. Налаштувати під своє місто

Найпростіше — відкрити Claude Code у папці радара й дати йому промпт із
**[SETUP_WITH_CLAUDE_CODE.md](../SETUP_WITH_CLAUDE_CODE.md)**. Він збере географію,
підбере канали, перевірить усе на реальних повідомленнях і підкаже кроки
з Telegram. Коли він пише `python3 …`, на Windows це `.venv\Scripts\python …`
(Claude Code знає це сам).

## 5. Telegram: бот, канал і вхід

1. У **@BotFather** створіть бота й отримайте токен.
2. Створіть канал для сповіщень, додайте бота адміністратором із правами
   «Публікація» та «Закріплення повідомлень».
3. Скопіюйте `.env.example` у `.env` і впишіть `BOT_TOKEN`, `TARGET_CHAT_ID`,
   а також `TG_API_ID`, `TG_API_HASH` (з my.telegram.org) і `TG_PHONE`.
   Токени вписуєте **ви самі** — не надсилайте їх у чат жодному AI.
4. Одноразовий вхід в акаунт, яким радар читатиме канали (краще другий,
   не основний): у папці радара в адресному рядку Провідника наберіть `cmd`,
   Enter, і виконайте `.venv\Scripts\python auth.py`. Код підтвердження прийде
   в Telegram.

## 6. Запуск

Подвійний клік по ярлику **«Радар міста»**. Біля годинника з'явиться кружок
(якщо не видно — він міг сховатися під стрілочкою ^; перетягніть його на панель).

| Колір | Що означає |
|---|---|
| 🟢 зелений | працює, тихо |
| 🟡 жовтий | оголошено тривогу по району, конкретної загрози місту немає |
| 🔴 червоний | недавно була загроза місту |
| сірий | пауза — сповіщення не надсилаються |
| помаранчевий | помилка; наведіть курсор, щоб побачити причину |

У меню: «Відкрити вікно», пауза, «Тиша на годину», звіти в канал, тестове
повідомлення, лог, папка з даними, вихід.

## Що важливо знати

* **Ноутбук не має засинати.** Параметри → Система → Живлення → Режим сну →
  «Ніколи» (хоча б коли підключено до мережі). Сплячий комп'ютер нічого не читає.
* **Файл сесії `data\session_monitor.session` = повний доступ до акаунта
  Telegram.** Не пересилайте його й не викладайте в інтернет.
* Робочі файли (`.env`, `data\`, `logs\`) лежать у папці радара й у git не
  потрапляють. Переносите радар на інший комп'ютер — у вікні є «Зберегти копію…»
  і «Відновити з копії…».
* Другий запуск ярлика не створює другого радара: якщо він уже працює, ви
  побачите повідомлення про це.
* Вимкнути автозапуск: `Win+R` → `shell:startup` → видалити ярлик «Радар міста».
